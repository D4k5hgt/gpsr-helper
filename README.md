# GPSR Helper

A free, browser-only tool that helps small sellers prepare products for the EU General Product Safety Regulation (GPSR).

**Live site:** https://d4k5hgt.github.io/gpsr-helper/

- Everything users type stays in their own browser. There are no accounts, server, cookies or AI.
- Anonymous visit counts via GoatCounter (cookieless), disclosed in the [privacy policy](privacy.html).
- Free. No payments, subscriptions or trials.

**Not legal advice.** See the [terms](terms.html).

## Run locally

```bash
python -m http.server 8765
```

Then open http://localhost:8765. Visits from localhost are not counted.
